## 1. 배경 및 문제 정의

- cbam 프로젝트 결과, CBAM 1차 적용 대상 중견 기업의 정보기술부문 투자액 중앙값은 14.3억 원임 (공시값 확보 27곳)
- 연 1억 원 설치형은 이 IT 예산의 약 7%에 해당함
- IT 인력 규모는 1단계에서 정보보호 공시로 재산출함
- 따라서 입구 비용은 IT 예산 밖, 즉 운영비(에너지비) 절감분에서 나와야 한다고 가정함
- 산업용 전기요금은 2021년 이후 kWh당 105.5원에서 182.7원으로 73.2% 오름

## 2. 핵심 질문

- **주 질문**: CBAM 1차 적용 중견 제조사가 IBM 유료 단계(3층)까지 N년 안에 스스로 비용을 대려면 에너지비를 연 몇 % 줄여야 하는가. 그 수준은 현실적인가
- **보조 질문**
  1. 한국 요금 규칙을 구현한 계산기로 실제 한국 공장 사례를 계산했을 때, 하루 전 예측(Granite TTM)이 기존 방식보다 요금 절감 여지를 더 만드는가
  2. 예측 기반 이동이 **예측 없이 고정 시간표로 옮기는 현장 관행**보다 절감액을 더 만드는가
  3. 그 사례에서 1층 비용을 회수하는 최소 부하 이동 비율(본전 비율)은 얼마인가
  4. 대상 기업별 필요 절감률이 외부 근거 범위 안에 들어오는가

## 3. 주장 범위

| 주장 | 근거 | 가능 여부 |
|---|---|---|
| 계산기가 현행 한전 요금 규칙을 정확히 구현함 | 약관 원문 + 수기 계산 | 가능 |
| 한국 사업장에서 예측 방법 간 정확도 차이 | UCI 1곳(15분) + 전남 제조업 93곳(1시간) | 가능 (한국 소규모 사업장 한정) |
| 예측 기반 이동이 고정 시간표보다 절감액을 더 만드는가 | UCI 사례 1건 | 가능 (사례 1건 한정) |
| 대상 기업의 에너지 규모가 IT 예산보다 훨씬 큼 | GIR 에너지 사용량 + 정보보호 공시 | 가능 (IT 공시값 있는 기업 한정) |
| 대상 기업의 필요 절감률 | GIR + 비용 가정 | 가능 (범위로 제시) |
| 대상 기업이 실제로 달성 가능한 절감률 | 없음 | 불가 → 1층 파일럿에서 측정 |
| 대상 기업의 연간 절감 금액 | 없음 | 불가 |

## 4. 범위

**포함**
- 대상: CBAM 1차 적용 업종(철강·알루미늄·시멘트·비료, 구조물·탱크·볼트너트 등 1차 가공품)의 중견 제조사

**제외**

- 부하 모양 변형을 통한 타 공장 일반화

## 5. 입구 설계 (3층 계단)

| 구분 | 1층 (입구) | 2층 (IBM 매출 시작) | 3층 (IBM 매출 확대) |
|---|---|---|---|
| 하는 일 | 공장 전체 전력을 가동 전에 예측, 생산 계획 조정 | 설비별 예측·관리 | 설비별 데이터를 탄소 보고 데이터로도 활용 |
| 데이터 | 한전 데이터 (고객 동의 기반, 공장 합계 1채널) | 배전반 계측기 직접 읽기 | 2층 데이터 누적분 |
| 도구 | 공개 모델 Granite TTM을 기존 서버 CPU에서 실행 | 같은 모델을 IBM 유료 소프트웨어로 이관 | watsonx.data |
| 비용 항목 | 연결 작업비 | 계측 공사비 + IBM 소프트웨어 | cbam 산출 설치형 비용 |
| IBM 수익 | 0 | 발생 | 확대 |

- Granite TTM r2: Apache 2.0, GPU 불필요. 파라미터 약 81만(과거 512구간)~308만(과거 1536구간)

## 6. 계약 장치

| 장치 | 내용 | 프로젝트 내 연결 |
|---|---|---|
| 기간 + 전환 기준 사전 합의 | 무상 기간을 두고, "파일럿에서 측정한 실제 절감률이 필요 절감률 이상이면 2층 전환"을 사전 합의함 | 5단계 필요 절감률을 전환 기준값으로 사용함 |

| 성과 연동 (ESCO 방식) | 1층 비용을 검증된 절감액의 일정 비율로 회수함 | 절감 측정 기준선은 tariff.py의 "이동 전 요금" 계산 방식을 그대로 사용함 |

## 7. 요금 규칙 (구현 대상)

- **최대수요전력**: 15분 단위로 누적 계산
- **요금적용전력**: 직전 12개월 중 12·1·2·7·8·9월분과 당월분 최대수요전력 중 최댓값. 계약전력의 30% 미만이면 계약전력의 30%
- **피크 산정 시간대**: 중간부하·최대부하 시간대만 (경부하 제외)
- **2026년 4월 16일 개편**
  - 최대부하 요금 평균 kWh당 15.4원 인하, 경부하 요금 5.1원 인상
  - 낮 11~15시 일부가 최대부하 → 중간부하, 저녁 18~21시가 중간부하 → 최대부하
  - 겨울철(11~2월)은 기존 시간대 유지
  - 봄·가을 주말·공휴일 낮 요금 할인(2030년까지)
  - 적용 유예 신청 시 9월 30일까지 기존 요금제 유지
- **요금제**: UCI 공장은 월 가동 약 127시간 → 산업용(을) 고압A 선택 I
- **공휴일·토요일**: 법정 공휴일 사용량은 경부하로 계량, 토요일 최대부하 사용량은 중간부하로 계량
- **제외 항목**: 연료비조정요금 등 kWh당 균일 단가 항목은 부하 이동과 무관하므로 제외하고 사유를 명시함

### 3단계: 예측 실험

- **데이터**
  - UCI: 15분, 매일 0시에 당일 96구간 예측, 2018년
  - 전남 제조업 93곳: 1시간, 매일 0시에 당일 24구간 예측, 1년 학습 → 1년 평가, **로컬 실행**
- **비교 대상 5종**
  1. 기존 장치 방식 (현재 15분 구간 안에서 끝값 외삽, UCI만)
  2. 계절 단순 예측 (전주 같은 요일·같은 시각)
  3. LightGBM (달력 변수)
  4. Granite TTM r2 제로샷 (과거 512·1024·1536구간)
  5. Granite TTM r2 퓨샷
- 참고용 천장: 완전 예측
- **휴무일 규칙**: 공장이 미리 정한 휴무일이면 예측값을 휴무일 평균 모양으로 바꾸는 규칙을 모든 방법에 동일하게 적용함
- **채점**: 24시간 전부 관측된 날만 채점함. 전남은 전체 93곳 / 100kW 이상 17곳으로 나눠 보고함
- **지표**: 일 최대 전력 예측 오차, 피크 구간 경보 적중률·오경보율, CPU 추론 시간
- **중단 지점**: TTM이 기존 방식보다 낫지 않으면 "1층은 기존 장치로 충분"을 결론으로 채택하고 1층 재설계로 전환함
- 퓨샷 학습 시간, 전남 로컬 실행 시간은 시작 전에 표본으로 측정함
- **산출물**: 모델 비교표, progress/03

### 4단계: 이동 시뮬레이션 + 사례 본전 비율

- `src/shift_sim.py` 구현. 하루 총 사용량은 보존함
- **이동 방식 3종 비교**
  1. **고정 시간표 이동 (기준선, 예측 없음)**: 매일 같은 시간대의 부하를 정해진 싼 시간대로 옮김. 현장 관행(야간 조업)을 흉내 냄
  2. 예측 기반 이동: 하루 전 예측상 피크 위험 구간의 부하를 비율 s만큼 옮김 (방법별)
  3. 완전 예측 이동: 실제값을 미리 안다고 가정한 천장
- **예측의 가치 = (2)의 절감액 − (1)의 절감액**
  - 차이가 없거나 음수이면 "1층 입구에 예측은 필요 없음"을 결론으로 채택함
- 2026년 개편 요금표로 계산하고, 개편 전 요금표로도 한 번 계산해 개편이 이동 효과를 얼마나 줄였는지 제시함
- 1층 비용 기준 본전 비율 s*를 산출함
- 2018년 부하에 2026년 요금을 적용한 반사실 계산임을 명시함
- **이 결과는 사례 1건이며 대상 기업에 이전하지 않음**
- **산출물**: 이동 방식별 절감액(s) 곡선, progress/04

### 5단계: 비용 가정 + 대상 기업 필요 절감률

- **비용 범위 설정** (공개 가격 없는 항목은 범위 가정)
  - 1층 연결 작업비, 2층 계측 공사비 + IBM 소프트웨어, 3층 cbam 산출값
- **에너지비 추정**: GIR 에너지 사용량(TJ) × 단가
  - GIR 에너지 사용량의 전력 환산 기준(3.6 또는 9.6 MJ/kWh) 확인 후 적용함
  - 전력 비중은 가공형·용해형별 범위로 가정함
  - 3개년 평균과 최신 연도 중 무엇을 쓸지 결정함 (가동 중단·합병 등 급변 기업 별도 처리)
  - GIR 미매칭 24곳은 목표관리 지정 기준(업체 200TJ) 미만으로 보고 상한값으로만 다룸
- **필요 절감률 산출**
  - 1층 비용 회수에 필요한 연간 에너지비 절감률
  - N년(3·5·7년) 안에 3층 누적 비용에 도달하는 데 필요한 연간 절감률
- IT 공시값이 있는 기업은 에너지비 ÷ IT 예산 배수를 함께 제시함
- **산출물**: 기업별 필요 절감률 표, 분포 그래프, progress/05

### 6단계: 근거 범위 대조 + 기업별 판정

- 필요 절감률을 외부 근거 범위와 대조함
- 외부 근거는 대부분 kW(피크) 기준이라 요금 % 환산에 추정이 들어감을 명시함
- **"야간 조업 보도 확인" 표시**
  - 보도로 야간·주말 조업이 확인된 기업은 이미 부하를 옮긴 상태라 추가 절감 여지가 작은 쪽으로 표시함
  - 현재 확인: 동국제강, 대한제강, 한국철강, 환영철강 (한국경제 2025-03-30, 메트로신문 2025-10-29, 머니S 2024-06-06)
  - 보도가 없는 기업은 "확인 안 됨"으로 둠
- **판정표**

| 결과 | 판정 |
|---|---|
| 필요 절감률 < 근거 범위 하단 | 성립 가능 |
| 필요 절감률 > 근거 범위 상단 | 불성립 |
| 그 사이 | 파일럿 측정 필요 |
| (별도) 야간 조업 보도 확인 | 추가 여지 작음 표시 |

- **산출물**: 기업별 판정 목록, progress/06

### 7단계: 계약 장치 설계서

## 10. 포지셔닝 주의

- "FEMS 구축"이 아니라 "입구 경제성 판정 계산기와 사례 검증"으로 표현함
- "피크 알림"이 아니라 "생산 계획 조정용 가동 전 예측"으로 기존 장치와 구분함
- CBAM 비용 절감은 주장하지 않음. CBAM 연결은 3층 데이터 활용으로만 서술함
- UCI 결과는 "한국 공장 1곳 사례"로만 표기함
- 예측이 고정 시간표보다 낫지 않으면 그 결과를 그대로 결론으로 씀

## 11. 한계

**데이터**
- UCI: 회사 실체 확인 불가, 소규모 공장 1곳, 2018년 1년치, 계약전력 미공개
- 전남: 1시간 단위라 15분 피크 계산 불가, 대부분 100kW 미만 소규모, 전남 5개 시만, 코로나 기간 포함, 100kW 이상 17곳 중 15곳이 나주
- GIR: 연간 총량(연료 포함)이라 전력 비중·부하 모양을 알 수 없음. "사업장" 지정 기업은 회사 전체보다 작게 잡힐 수 있음

**대상 기업**
- 비상장사는 배출권 명단을 통해서만 찾았으므로 배출권 비대상 비상장 중견사는 빠짐 (GIR상 미판정 금속·시멘트 법인 72곳 기록)
- 비상장사 매출은 대부분 2년 평균으로 판정함 (기준선 근처만 3년)
- 관계기업(모회사 지분) 규정은 cbam과 같게 적용하지 않음. 모회사·자회사 관계는 따로 표시함

**비용·효과**
- 연결 작업비, 계측 공사비, IBM 유료 소프트웨어 가격이 비공개라 범위 가정
- 외부 근거는 대부분 해외·타 업종·kW 기준
- 전기로 철강사의 야간 조업은 가동률이 낮을 때 가능한 방식이라 수요 회복 시 유지되지 않을 수 있음
- 2026년 요금 개편으로 경부하 요금이 오르고 낮 요금이 내려 야간 이동의 이점이 줄어듦
- 달성 가능 절감률은 파일럿 측정 전까지 확정 불가
