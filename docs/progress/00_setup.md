## 3. 데이터 1: UCI Steel Industry Energy Consumption

### 3-1. 기본 정보

| 항목 | 내용 |
|---|---|
| 출처 | UCI Machine Learning Repository (dataset 851) |
| 대상 | 전남 광양 소재 철강 공장 1곳, 2018년 1년치 |
| 단위 | 15분, 35,040행 × 11열 |
| SHA-256 | `9b1cee6f9cb9cd9df2b95814ca90a9a2ff15b7f5f1fba0fae3c643e82072eacc` (로컬·Kaggle 일치 확인) |
| 역할 | 한국 요금 규칙으로 원화 계산까지 하는 유일한 15분 사례. 요금 엔진 시연 + 예측 비교 사례 1건 |

### 3-2. 점검 및 보정

- 결측 0건, 사용량 0인 구간 1개(무시 가능)
- 자정 행이 다음날이 아닌 같은 날짜로 표기된 오류 365건 → +1일 보정함
- 시각이 구간 "끝" 기준으로 표기됨 → 15분을 빼서 구간 "시작" 기준으로 변환함
  - 근거: 월별 행 수가 시작 기준에서만 정확히 일치, 요일 표기가 시작 기준과 100% 일치
- CO2 열: 고유값 8개, 60%가 0, 거친 반올림 → 사용하지 않음. 간접배출은 사용량 × 공식 배출계수로 직접 계산함
- Load_Type 열: 한전 요금 규칙(공휴일, 토요일 처리)과 일치하지 않음 → 요금 엔진 정답지로 쓰지 않음

### 3-3. 공장 특성

| 지표 | 값 |
|---|---|
| 최대 15분 평균 전력 | 628.7kW |
| 연간 사용량 | 959.6MWh |
| 평균 전력 | 약 110kW |
| 부하율 | 약 17% |
| 하루 최저 전력 중앙값 | 약 11kW |
| 월 사용시간 | 약 127시간 → 산업용(을) 고압A 선택 I 적용 |

### 3-4. 하루 흐름 (평일 평균)

| 시간 | 평균 전력 | 해석 |
|---|---|---|
| 0~8시 | 약 20~35kW | 거의 정지 |
| 8시 | 약 300kW로 급등 | 설비 동시 가동, 하루 최대 피크가 8시 45분~9시에 발생 |
| 12~13시 | 약 30kW | 점심시간 |
| 13~17시 | 약 280kW | 오후 가동 |
| 18~21시 | 약 215kW | 저녁 잔업 (수요일은 확연히 낮음) |
| 21시 이후 | 약 40~60kW | 종료 |

- 토요일은 평일의 약 절반 수준으로 17시까지 가동함
- 월별 최대 전력은 490~630kW로 1년 내내 비슷함. 래칫 기준 월(12·1·2·7·8·9월) 중 최댓값은 1월(약 612kW)

### 3-5. 휴무일 확인

| 구분 | 하루 사용량 | 판단 |
|---|---|---|
| 평일 중앙값 | 약 3,119kWh | 기준 |
| 근로자의 날, 여름휴가(8/1~3), 12/31 | 약 270~340kWh | 공장 휴무 |
| 설·추석·신정·성탄절 | 약 260~350kWh | 공장 휴무 |
| 5/7, 5/22, 6/6, 8/15, 10/3, 10/9 | 약 2,000~4,900kWh | 법정 공휴일이나 가동 |
| 3/1, 6/13 | 약 1,400~1,700kWh | 축소 가동 |

- Load_Type의 휴무 표시는 한전 공휴일이 아니라 공장의 실제 휴무일을 반영한 것으로 판단함

## 4. 데이터 2: AI허브 전라남도 지역 전력소비패턴 데이터

### 4-1. 기본 정보

| 항목 | 내용 |
|---|---|
| 출처 | AI허브 「전력신사업을 위한 전라남도 지역 전력소비패턴 데이터」 (2022년 구축) |
| 사용 범위 | 기업 360곳 중 제조업 93곳 |
| 기간·단위 | 2020-09-01 ~ 2022-08-31 (2년), 1시간 단위 |
| 역할 | 예측 방법 비교를 한국 여러 사업장으로 확대. 원화 절감액 계산에는 쓰지 않음 |
| 시각 기준 | 구간 시작 표기 (주간 사업장 평일 점심 하락이 12시에 나타남) → 변환 없음 |

### 4-2. 이용정책 준수

- 국외 반출은 별도 합의가 필요함 → Kaggle 등 해외 서버에 올리지 않고 로컬에서만 처리함
- 제3자 제공·열람 금지, 단순 가공본 공유도 불가 → 원본·가공 파일은 GitHub에서 제외함(`.gitignore`)
- 코드와 결과(표·그래프)만 공개함. 사업장은 익명(A, B…)으로 표기함
- 출처 표기: "본 프로젝트는 과학기술정보통신부와 한국지능정보사회진흥원의 사업결과인 AI 허브 「전력신사업을 위한 전라남도 지역 전력소비패턴 데이터」를 활용함"

### 4-3. 제조업 93곳 구성

| 구분 | 분포 |
|---|---|
| 직원 수 | 30인 이하 62곳, 30~50인 22곳, 50인 이상 9곳 |
| 근무 형태 | 주간 68곳, 야간 17곳, 주야간 8곳 |
| 지역 | 순천 27, 나주 25, 여수 18, 목포 14, 광양 9 |
| 규모 (상위 0.1% 값 기준) | 100kW 미만 76곳, 100kW 이상 17곳(그중 300kW 이상 6곳) |

### 4-4. 정리 규칙

| 문제 | 처리 |
|---|---|
| `0.001` 값 (기록 없음 표시) | 길이와 관계없이 전부 결측 처리함. 평일 낮에도 1시간짜리가 많아 실제 0으로 볼 수 없음 |
| 여러 사업장 동시 수집 중단 | 2022-02-23~03-03(최대 45곳), 2022-03-25~27(최대 60곳) |
| 급등값 | 1건(평소 최댓값의 약 5,400배) 결측 처리함 |
| 결측 채우기 | 하지 않음. 3단계에서 24시간 전부 관측된 날만 채점함 |

- 정리 후 결측 비율 2.16%, 사업장별 완전한 날 수 중앙값 700일(최소 435일)
- 100kW 이상 17곳은 1곳(결측 약 12%)을 제외하면 결측 1% 미만

0단계 첫 점검 때 보류로 둔 결정은 2가지였음.

| ② 공휴일 목록 | `check_holidays.py`, `check_operating_days.py` 실행 | 요금 계산은 법정 공휴일 달력 사용, Load_Type 사용 안 함 |

## 7. 확정 결정

| 항목 | 결정 |
|---|---|
| 예측 시점 | 매일 0시에 당일 전체를 예측함 (UCI: 15분 × 96구간, 전남: 1시간 × 24구간). 근거: 달력 하루와 모델 출력 길이가 일치, 전날 데이터를 모두 사용, 야간·주야간 사업장을 포함한 모든 사업장에 같은 규칙 적용 가능. UCI 공장 기준 가동 시작(8시) 약 8시간 전 |
| 요금 계산 공휴일 | 법정 공휴일 달력 기준. Load_Type 사용 안 함 |
| 예측 시 휴무일 | 공장이 미리 정한 휴무일이면 예측값을 휴무일 평균 모양으로 바꾸는 규칙을 모든 방법에 동일하게 적용함 |
| 래칫 처리 | 데이터가 1년치라 직전 12개월을 채울 수 없음 → 2단계에서 "전년도도 동일" 가정으로 계산하고 한계로 명시함 |
| 실행 장소 | UCI는 Kaggle, 전남은 로컬 |
| 파라미터 표기 정정 | "80만" → "약 81만~308만 (과거 길이에 따라 다름)" |

## 8. 남은 확인 사항

1. 대체공휴일(5/7)과 선거일(6/13)이 한전 요금상 공휴일에 포함되는지 (약관 원문)
2. 산업용(을) 2026년 요금표 원문 단가
3. UCI 공장 계약전력 가정값 (30% 하한 규칙 적용에 필요)
4. 전력 공식 배출계수
5. NGMS 명세서 배출량 통계 최신 연도 확보
6. cbam 설치형 연 1억원대에 구축·운영 서비스비 포함 여부
7. 고압 고객이 한전 전력데이터 제3자 동의 대상인지 (한전 문의)
