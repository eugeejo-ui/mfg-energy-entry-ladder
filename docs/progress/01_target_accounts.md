# 1단계: 대상 기업 데이터 구축

## 1. 목적

- 입구(전기요금 절감) 후보가 될 에너지 다소비 중견 제조사 명단을 만듦
- 회사별 에너지 사용량, 공장 종류, IT 규모를 붙여 5단계 계산의 입력표를 만듦
- 세그먼트(A·B·C)와 후보 층(확정·잠재), 에너지 규모 구간을 정함

## 2. 결과 요약

| 세그먼트 | 확정 | 잠재 | 확정 중 GIR 에너지 자료 있음 |
|---|---|---|---|
| A (시멘트·비료) | 10 | 4 | 10 |
| B (철강·알루미늄·가공) | 63 | 15 | 39 |
| C (비CBAM) | 172 | 236 | 172 |
| 합계 | 245 | 255 | 221 |

- 확정: 중견 판정 완료. 5단계 계산 대상
- 잠재: CBAM·제조업 여부는 확인, 규모 미판정. 수만 기록해 잠재 매출 최대치에 사용

## 3. 세부 진행

### 1-1. 상장 중견·CBAM 1차 58곳

- cbam 레포 커밋 `001ca4c`의 `mfg_final_reviewed.csv`, `it_spend_matched.csv`를 `data/external/cbam/`으로 가져옴
- 조건: 중견, 지주회사 아님, CBAM 1차 적용
- 정정: 대화 중 먼저 계산한 "1차금속 비소속 13개사, IT 중앙값 8.9억"은 정보보호 공시 명단에서 출발한 좁은 정의라 폐기하고 cbam 기준으로 통일함

### 1-1b. 비상장 배출권 1차 업종 32곳 판정

- 대상: 배출권 할당대상 중 CBAM 1차 업종인데 상장사와 매칭 안 된 32곳 (cbam `kets_unmatched_wave1.csv`)
- 절차: DART 회사 코드 → 법인등록번호로 기업집단 대조 → 매출·자산 확보 → 중견 판정
- 규칙
  - 상호출자제한집단(자산 12조 이상) 소속 = 대기업, 공시대상집단 소속 = 중견, 그 외는 매출·자산 기준 (cbam과 동일)
  - CBAM 해당 여부와 규모 기준 모두 배출권 명단 업종코드 하나로 판정
  - 매출은 감사보고서 2년 평균, 기준선 근처(±20%)는 3년 평균으로 재판정
  - 외국계 대기업 자회사·합작사는 제외
- 매출·자산: 사업보고서가 있는 4곳은 DART API, 19곳은 감사보고서 육안 확인 후 `step1_finalize_targets.py`에 원 단위로 기록

### 1-2. GIR 명세서 확보

- 온실가스종합정보센터 명세서 배출량 통계 2023·2024·2025 (`data/raw/gir/gir_20XX.xls`, 2026-09-26 다운로드)
- 정리 규칙
  - 2023년 파일의 완전 중복 행 제거 (1,540 → 1,154행)
  - 쉼표 제거 후 숫자 변환, 비공개(`*****`)는 빈칸
  - 같은 법인·연도에 "업체" 행이 있으면 그것만, 없으면 "사업장" 행 합산
- GIR 법인 1,282곳

### 1-3. GIR 매칭

- 배출권 명단 이름 → DART 회사명 순으로 이름 매칭
- 배출권 대상 40곳(상장 25 + 비상장 15) 전부 연결
- 배출권 비대상 상장 33곳 중 9곳 연결(목표관리 등), 24곳은 신고 기준 미만
- 업종명이 "기계"로 적힌 3곳(삼화왕관, 아주스틸, 대양금속)은 이름이 정확히 일치해 인정

### 1-4. 공장 종류 구분 (A·B 73곳)

- 방법: 업종코드 1차 분류 → 보고서 증거 문장(주요 사업, 원재료) → 에너지 집약도(TJ/매출 억 원) 교차 확인. 판정은 `data/manual/step1_type_decisions.csv`
- 결과: 가공 45, 철강 용해(전기로·합금철) 11, 시멘트(소성로) 7, 비철 용해 4, 혼합 3, 시멘트(분쇄형) 2, 비료·화학 1
- 확신도: 확정 62, 추정 9, 불확실 2 (삼목에스폼, 하이호경금속)
- 업종코드에서 바뀐 곳: 와이케이스틸(가공 → 철강 용해, "빌렛 제조" 명시, 집약도 0.98), 조일알미늄·삼아알미늄(가공 → 혼합), 한국씨엔티(시멘트 → 분쇄형), 대한시멘트(분쇄형 추정)
- 방법상 교훈
  - 단어 개수만으로는 연혁과 현재 설비를 구분 못 함 (KG스틸 "전기로"는 연혁)
  - 감사보고서에는 설비 설명이 거의 없어 원재료 단서가 더 유효함
  - 매출 기준 집약도는 금속 종류가 다르면 비교 불가 (알루미늄은 톤당 가격이 높아 낮게 나옴)
  - 철강 용해 0.69~0.92, 철강 가공 0.04~0.48로 철강 안에서는 뚜렷이 갈림

### 1-5. 에너지 vs IT 비교

- 정보보호 공시의 공시연도는 투자연도 + 1 (2025년 투자액 → 2026년 공시)
- 상장 27곳: IT 투자 중앙값 14.3억 원, IT 인력 7.0명, 총 임직원 424명
- 에너지·IT 둘 다 있는 21곳: 순위 상관 0.45
- 에너지 크고 IT 작은 회사: 한국특강(6,247TJ / 7.5억 / IT 3명), 태웅(2,902TJ / 6.9억), 동일산업(2,559TJ / 4.8억), 아세아시멘트, 성신양회
- 에너지 대비 IT 큰 회사: 동국제강, 동국씨엠, KG스틸, TCC스틸 (앞의 셋은 기업집단 소속)
- 비상장 15곳: 공시 없음
  - 기업집단 비소속 상장사 매출 대비 IT 비율(하위 25% 0.123%, 중앙 0.193%, 상위 25% 0.525%) 적용 → 대부분 연 4~11억 원
  - 감사보고서 소프트웨어 취득액은 연 0~약 5.9억 원 (인건비·유지비 제외 최소값)

### 1-8. 세그먼트 C 규모 파악

- GIR 법인 중 cbam 상장 목록 밖 961곳 DART 조회 (조회 결과 `data/raw/dart/company_cache.json`에 저장)

| C 비상장 (규모 미판정) | 236 |
| C 비상장 (공시대상집단 소속 = 중견) | 24 |
| DART 미매칭 | 217 |

- C 확정: 상장 중견 148 + 공시대상집단 소속 비상장 24 = 172
- 가설 결과
  - H1 비CBAM 후보가 더 많다: 맞음 (확정만 172곳)
  - H2 비CBAM은 에너지가 작다: 절반만 맞음 (중앙값 비슷, 상위권은 A·B가 큼)
  - H3 전기 많이 쓰는 업종이 있다: 미확인 (화학 85, 자동차 49, 전자부품 45, 비금속광물 37, 제지 36곳)
  - H4 비CBAM은 확대 동기가 약하다: 6단계에서 조사

## 5. 정정 기록

| 정정 | 내용 |
|---|---|
| 대상 정의 | "13개사"는 좁은 정의라 폐기, cbam 기준(중견·CBAM 1차)으로 통일 |
| IT 연도 | 정보보호 공시 연도를 투자 연도로 착각해 1년 전 값을 가져왔던 것을 수정 |
| 공장 전력비 | 61곳에서 전력비 문장이 나왔으나 상당수가 판관비 수도광열비(사무실)였음. 공장 전력비 공개 회사 수는 5단계에서 별도 확인 |
| SIMPAC | 에너지 감소 원인을 당진공장 중단으로 단정했던 것을 "확인 불가"로 수정 |

## 6. 한계

- 비상장사는 배출권·GIR 명단으로만 찾음, DART 미매칭 217곳·동명 38곳 미확인
- 잠재 후보에는 중소기업·외국계 계열사가 섞여 있을 수 있음
- 비상장사 매출은 대부분 2년 평균, IT 예산은 추정치뿐

- 에너지 사용량은 연료 포함 총량이라 전기요금 규모와 순위가 다를 수 있음
